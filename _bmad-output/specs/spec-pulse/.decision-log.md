## 2026-06-14 — Open questions resolved by Fred

**Q1 — Task config location:** Confirmed `data/agent-yana/pulse-tasks.yaml`. Moved to Constraints.

**Q2 — Session writing without YANA dependency:** Fred asked to avoid large-scale code coupling. Decision: Pulse writes session files directly to `data/agent-yana/sessions/` following the documented file format — no imports from the YANA orchestrator. Acoplamento por contrato de arquivo, não por código. Moved to Constraints.

**Q3 — YANA↔Pulse IPC:** Fred's model: Pulse is always running; YANA is ephemeral. He proposed a fast network protocol. Decision: Pulse exposes a lightweight localhost HTTP API. YANA calls it via POST when creating/updating/removing tasks. No shared memory, no direct imports, no polling. Moved to Constraints.
